PGLife - Property Listing Web Application

PGLife is a web application that helps users find PG accommodations easily.

Features
- User Login & Signup
- Property Listing
- Property Details Page
- Filters (Gender, Rent)
- Rating System

Tech Stack
- HTML
- CSS
- Bootstrap
- JavaScript
- PHP
- MySQL

Setup
1. Install XAMPP
2. Start Apache & MySQL
3. Import database
4. Run project on localhost
